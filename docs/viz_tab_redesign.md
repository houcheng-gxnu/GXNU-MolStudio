# 「可视化」tab 右侧设置区 重设计

> 现状实测于 `main_window.OrbitalVisApp()`，右栏滚动视口 665×681。
> 复现脚本：`_viztab_probe.py`（结构 dump）、`_stylebar_*` 系列（卡片侧）。

## 1. 现状诊断（全部为实测值，非估计）

### 1.1 体量

| 指标 | 实测 |
|---|---|
| 参数面板尺寸 | 653 × **2300** px |
| 右栏滚动视口 | 665 × **681** px |
| 需要滚动 | **1619 px ≈ 3.4 屏** |
| 可设置项 | 60+（28 个滑块、22 个输入框、13 个复选框、11 个下拉、19 个按钮） |
| 折叠组 | 3 个（其中 2 个标题为空、默认全展开） |

### 1.2 根本问题：同一件事用了三套布局机制

| 折叠组 | 布局 | 标签列宽 | 控件起点 x | 滑块最小宽 | 数值框 |
|---|---|---|---|---|---|
| 显示 / 等值面（24 行） | `QVBox` + 每行一个 `HBox` | 硬编码 `LBL_W = 110` | 118 | 120（实际拉伸到 409） | `setFixedWidth(64)` |
| 球棍模型（53 项） | `QGridLayout` 4 列 | 自动 → **152** | 177 | `setMinimumWidth(200)` | `setMaximumWidth(64)` |
| vdW 外壳（14 项） | 第三种写法 | 自动 → **129** | 154 | 329 | 64 |

同一个面板里 **三套标签列、四个控件起点 x（118 / 154 / 177 / 206）**。
这就是"看着乱"的第一来源——不是颜色或间距，而是**没有同一条基准线**。

### 1.3 六处"特殊行"把栅格撕开

| 行 | 现状 | 实测坐标 |
|---|---|---|
| `天顶/地面色:` | 一格里塞两组"标签+色块"，靠 stretch 顶到两边 | 标签 0/126/459/539；控件 206/539 |
| `透明合成:` | 一行三组参数 | `透明合成`@118、`网格精度:`@248、`剥离层数:`@457 |
| `等值面描边` | 复选框占了标签位，后面跟两组 | 复选框@0、`粗细:`@141、`描边颜色:`@440 |
| `启用色轮配色` 行 | 复选框 + 84px 色轮 + 下拉 + 重置，四种东西一行 | 0 / 160 / 252 / 351 |
| `呼吸:` 行 | 复选框 + stretch + `重置视角` 按钮（**功能毫无关系**） | 0 / 501 |
| `灯光:` 行 | `光源设置…` + stretch + `样式: 保存… 载入…`（**两组功能硬凑**） | 118 / 315 / 433 / 520 |

### 1.4 节奏不齐

- 行高取值 **5 种**：39 / 37 / 32 / 27 / 26 px
- 行间距 **2 种**：8（等值面组）/ 4（球棍、vdW 组）
- 滑块宽度 **7 种**：409 / 397 / 364 / 356 / 329 / 200 / 160 / 158
- 数值格式混用：`0.06` `21` `0.050` `1.68` `0.400` `0.08` `8.0` —— 同一个界面里 2 位/3 位/整数随机出现

### 1.5 命名不一致

同一概念多种叫法：`等值面大小:` / `vdW 半径:` / `原子半径:` / `键收腰:`；
`描边粗细:` / `外壳描边粗细:` / `粗细:`；`化学键:`（其实是键半径）。

### 1.6 没有二级分节

「显示 / 等值面」组里 **24 行平铺**，把光照、材质、原子配色、等值面、相位配色、
灯光/样式 I/O 全混在一起。用户找"粗糙度"要滚过 10 行光照参数。

## 2. 设计目标

1. **可扫视** —— 打开就能看到全部小节标题，一眼知道东西在哪
2. **可预测** —— 同类参数长在同一个位置、同一种样子
3. **可扩展** —— 加新参数不改布局代码，只加一行 `_row(...)`
4. **可回归** —— 版面能用脚本量化验收（见 §8），不靠肉眼

**明确不做**：不改任何控件的信号连接、不改渲染逻辑、不改参数语义。
这是纯版面重构。

## 4. 行栅格规范

### 4.1 常量

| 常量 | 值 | 说明 |
|---|---|---|
| `ROW_H` | **28** | 所有行统一高度（滑块/复选框/下拉/标签） |
| `ROW_GAP` | **6** | 行间距 |
| `LBL_W` | **实测最大值** | 不再硬编码；切语言后重测（复用 `esp_panel._align_lead_labels()` 的写法） |
| `COL_X` | `LBL_W + 8` | 控件列统一起点 |
| `NUM_W` | **64** | 数值框固定宽，等宽字体（Consolas），右对齐 |
| 行尾按钮 | 紧跟控件列，左对齐 | 不顶到右边（顶右会造成按钮各自为政的一堆右边缘） |
| 滑块行右边缘 | 数值框左边 − 8 | 由 `stretch` 保证唯一 |
| 分组内边距 | 8 / 6 / 8 / 6 | 统一 |
| 分组间距 | 10 | 统一 |

**关键改动**：`LBL_W` 从"硬编码 110 + `setMinimumWidth`"改成"实测最长标签 + `setFixedWidth`"。
现在 `setMinimumWidth` 允许标签撑宽（`天顶/地面色:` 就要 118），
所以同一组的标签右边缘有 110/118/122/133 四种值。

### 4.2 七种标准行模板

```
滑块行     [ 标签            ] [ 滑块 ──────────────────── ] [ 0.06 ]
开关行     [ 标签            ] [☑]                              ← 勾选框紧贴 COL_X
开关+滑块  [ 标签            ] [☑] [ 滑块 ──────────────── ] [ 0.06 ]
下拉行     [ 标签            ] [ 下拉 ───────────────────── ]
数值行     [ 标签            ] [ 输入框 64 ] [ 单位 ]
颜色行     [ 标签            ] [ ■ 色块 64 ] [ #RRGGBB ]
按钮行     [ 标签            ] [ 按钮 ] [ 按钮 ]                ← 左对齐，不顶到右边
弹窗入口   [ 标签            ] [ 按钮… ]
```

滑块一律 `stretch=1` 吃满剩余宽度 → **滑块左边缘 = COL_X，右边缘 = 数值框左边 − 8**，
全面板只剩**一条**滑块基准线（现在有 7 种宽度）。

### 4.3 数值框规范

| 参数类别 | 格式 | 例 |
|---|---|---|
| 比例 / 强度（0–1） | `%.2f` | `0.06` |
| 半径 / 长度（绘制单位） | `%.2f` | `1.68` |
| 阈值（量级很小） | `%.3f` | `0.050` |
| 像素 / 层数 / 段数 | `%d` | `8` |
| 角度 | `%.0f°` | `45°` |

统一用等宽字体 + 右对齐，数值跳变时不会左右抖。

## 5. 命名与文案对照

| 现在 | 改为 | 理由 |
|---|---|---|
| `化学键:` | `键半径:` | 它调的是半径，不是"化学键" |
| `等值面大小:` | `等值面阈值:` | 与代码里的 iso / 阈值一致 |
| `等值面描边` / `粗细:` | `描边:` / `描边粗细:` | 去掉"等值面"，因为已在"等值面"节内 |
| `外壳描边粗细:` | `描边粗细:` | 已在"vdW 外壳"节内，前缀冗余 |
| `WBOIT 衰减:` | `透明衰减:` | 不暴露实现缩写 |
| `剥离层数:` | `透明层数:` | 同上 |
| `后处理抗锯齿` | `抗锯齿:` | 补冒号，统一"名词:"形式 |
| `景深雾化` / `原子描边` / `呼吸` / `翻转相位` / `线性空间光照` / `启用色轮配色` | 全部补冒号 | 开关行的标签也要有冒号，才能和滑块行对齐 |

## 6. 六处特殊行的处理

| 现状 | 改为 |
|---|---|
| `天顶/地面色: [天顶色:■] … [地面色:■]` | **两行**：`天顶色: [■]` / `地面色: [■]` |

## 7. 顶部固定条（新增）

不随滚动消失，36px 高：

```
[样式: 保存… ] [载入… ] [重置视角]        [全部展开] [全部折叠]     ← 右对齐
```

理由：`保存/载入/重置视角` 是"随时可能想点"的动作，现在埋在 2300px 列表的第 ~1150 行和
最底部，要滚 1.7 屏才够得着。

## 附：参数区的「样式 保存 / 载入」覆盖情况

参数区 60 行设置共 79 个可调控件。原先的 `get_style_state()` 只存 44 个键，
往返审计（`_style_roundtrip_probe.py`）实测 **30 个控件存了也对不上**。

`_sync_style_ui()` 回填 8 组。现在 **73/73 完整往返，渲染结果逐位一致**。

**按设计不进样式文件**：等值面阈值、网格精度、导出透明背景、键长标注、
vdW「仅选中片段」+片段编号 —— 与"逐键多重键指定属场景内容"同一条标准。

### 高度账（实测，非估算）
| | 改动前 | 改动后 |
|---|---|---|
| 默认展开 | 2300px（两组全展开） | **676px**（只展开①，免滚动） |
